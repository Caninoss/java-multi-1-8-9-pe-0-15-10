# Java Multi 1.8.9 + PE 0.15.10

Pacote de servidor Genisys PE 0.15.10 com uma ponte para jogadores Minecraft Java 1.8.x. O mundo incluído está em `servidor/worlds`; você pode substituí-lo por outro mundo compatível.

## Comece por aqui

Leia [`LEIA-PRIMEIRO.md`](LEIA-PRIMEIRO.md) antes de iniciar. O guia explica os requisitos da hospedagem, o comando de inicialização e as portas de Java e PE, em português, inglês e espanhol.
